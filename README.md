# Power BI Assignment 2 – DAX & Data Visualization

## 📌 Project Overview
This project focuses on sales data analysis using Microsoft Power BI, DAX calculations, and interactive visualizations to understand sales performance and regional trends.

## 🎯 Objectives
- Analyze actual sales compared with sales targets.
- Identify sales trends across categories and months.
- Visualize sales distribution across cities and sub-categories.
- Analyze order counts across different states.
- Create DAX measures for sales target analysis.

## 📊 Visualizations

### 1. Sales Performance Matrix
Compares actual sales with sales targets across different categories and time periods.

### 2. Geographic Sales Analysis
Visualizes total sales by city to identify regional sales patterns.

### 3. Sales Distribution by Sub-Category
Uses a treemap to represent sales distribution across different sub-categories.

### 4. Order Count Analysis by State
Uses a funnel chart to visualize order counts across different states.

### 5. Sales Target Analysis
Uses DAX measures to analyze minimum sales targets across categories.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

## 📈 Key Learning Outcomes
- Data modeling and relationships
- Creating DAX measures
- Building interactive Power BI visualizations
- Analyzing sales performance and targets
- Presenting data-driven insights
